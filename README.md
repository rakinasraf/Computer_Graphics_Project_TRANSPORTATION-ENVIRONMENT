# 🚦 Transportation & Environment — Computer Graphics Project

A Computer Graphics project focused on visualizing transportation and environmental elements through computer-generated graphics and interactive scenes.

## 📌 Project Overview

The **Transportation & Environment** project demonstrates how computer graphics can be used to represent transportation systems and surrounding environments visually. It was developed as an academic project to apply fundamental computer graphics concepts to a real-world-inspired scenario.

The project explores graphical scene design, object representation, and the visual interaction between transportation and the environment.
